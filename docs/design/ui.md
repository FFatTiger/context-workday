# Context v1 界面规范

本文管界面"长什么样、怎么交互"。行为规则以 `.scratch/context-v1/spec.md` 为准，术语以 `CONTEXT.md` 为准。

## 0. 视觉基准：可点击原型（优先于本文第 1、2 节和所有颜色描述）

视觉和布局以 `docs/design/prototype/index.html` 为准（浏览器直接打开，可点击）。截图：`today.png`、`drawer.png`、`review.png`、`backup.png`、`tasks.png`。搜索页、设置页没有原型，沿用同一套变量和组件。

原型取代了旧版"暗色观测台"风格。本文第 3 节以后的组件结构、状态、交互和文案规则仍然有效，只是颜色、布局按下面的对照换掉：

| 旧描述 | 现在 |

## 1. 总体

- 只做桌面端，最小宽度 1280px。比这更窄时出现横向滚动，不做响应式改版。
- 风格是暗色"观测台"：深蓝黑底、细边框面板、克制的强调色。层级靠字号和亮度区分：结论大而亮，元信息小而暗。
- 文案用简体中文。时间、数量、版本号用等宽数字。
- 页面只负责布局和组合，所有视觉样式都在共享组件里，从第 2 节的设计变量取值。

## 2. 设计变量

### 颜色

| 变量 | 值 | 用途 |
|---|---|---|
| `bg` | #0A0E14 | 页面底色，叠一层极淡点阵（2px 点、24px 间距、4% 透明度） |
| `bg-sidebar` | #080B10 | 侧栏底色 |
| `panel` | #10151D | 卡片、面板 |
| `panel-raised` | #121821 | 抽屉、弹窗、文档式卡片 |
| `border` | #1E2733 | 1px 细边框、分隔线 |
| `text-1` | #E8ECF2 | 主文字：摘要条目、标题 |
| `text-2` | #8B95A5 | 次要文字：元信息、标签 |
| `text-3` | #566070 | 弱化文字：占位、未来、禁用 |
| `amber` | #F2B544 | 当前、选中、"今天"标记、版本徽标、"修改"标记 |
| `cyan` | #4CC3E6 | 证据、原文、链接、主按钮 |
| `green` | #5FD3A0 | 成功、已备份、"新增"标记 |
| `coral` | #F07A6A | 失败、丢失、告警、"删除"标记、待回复 |

强调色的浅底一律用该色 12% 透明度，描边用该色 60% 透明度。

**降级**的样式固定为：琥珀色虚线描边，加一个警示三角图标，丢失说明的文字用珊瑚色。

### 字体和字号

| 用途 | 字号 / 字重 |
|---|---|
| 页面大标题（日期、页名） | 30 / 600 |
| 卡片标题 | 18 / 600 |
| 摘要条目 | 15 / 400，行高 1.6 |
| 正文、按钮 | 14 / 400 |
| 元信息、标签、角标 | 12 / 400 |
| 时间线的小时标签 | 14 / 500，等宽 |

字体用系统中文无衬线（PingFang SC / 微软雅黑）。数字开启等宽数字。

### 间距、圆角、阴影

- 8px 网格；页面内边距 32；卡片内边距 20；卡片之间间距 16。
- 圆角：卡片 12，输入框和按钮 8，胶囊和角标用全圆角。
- 阴影只用在抽屉和弹窗上；其他层级靠边框和底色区分。

### 图标与动效

- 图标：单色线性，线宽 1.5，尺寸 16 / 20。
- 抽屉从右侧滑入，240ms，ease-out；遮罩淡入 200ms。
- 悬停：边框提亮到 `text-3`，过渡 150ms。
- 生成中用骨架屏和"正在生成…"文字，不用旋转大图标。

## 3. 应用框架

### 侧栏（宽 220）

- 顶部：Logo（细线圆环加轨道小点），"Context"，下面一行小字"工作日镜"。
- 导航（顺序固定）：今天、回顾、搜索、备份、任务、设置。当前项左侧有 2px 琥珀竖条，文字提亮。
- 底部：
  - "● 本机运行"（绿点）；
  - "IM 已备份 N 天"；
  - "演示脱敏"开关（和设置页是同一个状态）。

### 页头

每个页面的第一行：左边是页面标题区和本页控件，右边是全局区（搜索框"搜索… ⌘K"）。状态胶囊只在今天页显示。

### 告警横幅

有备份告警时，在所有页面的页头上方显示一条全宽横幅：珊瑚色浅底、珊瑚色描边。

- 文案："IM 备份失败 · 还剩 N 天可补救"，右边是"去处理 ›"，点击跳到备份页。
- 邮件告警文案："邮件备份失败 · 还剩 N 天可补救"。
- 告警消失后横幅也随之移除。

### 全局快捷键

- ⌘K / Ctrl+K：聚焦页头搜索框；回车跳到搜索页并带上关键词。
- Esc：关闭抽屉或弹窗。

## 4. 共享组件

### 状态胶囊

圆角胶囊，左边一个状态点，右边文字。点的颜色：绿 = 正常，珊瑚 = 失败，琥珀 = 进行中。例如"● IM 备份 今天 02:00"、"日结 20:30 已生成"。

### 版本徽标

琥珀描边的小胶囊，内容是版本号加时间加方式，按场景取：

| 场景 | 示例 |
|---|---|
| 日结 | "日结 v1 · 20:30" |
| 增量更新的周 / 月 | "v4 · 今天 20:30 增量" |
| 小时 v2 及以上 | "v2 · 手动重跑" / "v2 · 迟到重跑" |
| 最终版 | "v5 · 最终版" |

小时 v1 不显示徽标，只显示"10:05 生成"。

### 上游已变更标记

琥珀描边胶囊"上游已变更 · 重建"，可以点击。点击后弹出确认框，确认后执行重新生成。

### 证据角标

小胶囊，青色描边，青色文字。

- 类型："原文 n"、"邮件 n"、"日程 n"（用于小时条目），"证据 n"（用于日结及以上的条目）。
- "降级 n"用降级样式：琥珀虚线描边，加警示三角。
- 点击角标和点击条目一样，打开证据抽屉。

### 条目行

- 结构：圆点 + 条目文本（`text-1`）+ 可选的本版操作标签 + 右对齐的角标组。
- 本版操作标签只在回顾页显示：
  - "v4 新增"：绿色描边；
  - "v4 修改"：琥珀描边。
- 整行可点击，悬停时出现浅底；点击打开证据抽屉。
- 文本最多显示两行，超出部分用省略号，悬停时显示全文。

### 摘要卡

- 结构：
  - 头部：标题、日期范围（`text-2`）、右侧版本徽标；
  - 中间：条目行；
  - 页脚：一行 `text-2` 小字。
- 状态：

| 状态 | 显示 |
|---|---|
| 已生成 | 条目列表 |
| 未生成 | "今日日结将在 20:30 生成"（时间取任务配置）+ 青色按钮"立即生成" |
| 生成中 | 3 行骨架 + "正在生成…" |
| 失败 | 珊瑚色"生成失败"+ 原因一行 + 按钮"重试" |
| 无记录 | "这一天没有与我有关的记录"（`text-3`） |
| 上游已变更 | 头部多一个"上游已变更 · 重建"标记，条目照常显示 |

### 时间轨与小时卡

- 时间轨：左侧是等宽的小时标签（"09:00"），一条竖细线，每个有记录的小时在线上有一个青色圆点。
- 小时卡：挂在对应小时右侧的面板。
  - 头部：元信息"10:05 生成"，或者版本徽标；
  - 中间：条目行，最多 3 条；
  - 悬停时右上角出现"重新生成"图标按钮。
- 空档行：两张卡之间的空档用虚线段加一行 `text-3` 说明：
  - 连续多小时："12:00 – 14:00 无与我有关的消息"；
  - 单个小时："17:00 无记录"。
- 当前时刻（只在今天显示）：轨道底部一个琥珀发光点，旁边是等宽的"20:36"，后面跟 `text-2` 小字"下次小时摘要 21:05"。
- 失败的小时：卡片显示珊瑚色"生成失败 · 重试"，点击即重跑。
- 生成中的小时：卡片显示骨架。
- 时间线从当天第一个有记录的小时开始，前面没有空档行。

### 抽屉

- 从右侧滑出，宽度为视口的 46%（最小 560px），高度占满。
- 底色 `panel-raised`，左侧细边框，带阴影。
- 背景遮罩：页面压暗 60%，加 4px 模糊。
- 头部：标题和"×"按钮。Esc 或点遮罩可关闭；打开期间焦点限制在抽屉内。

### 证据树

- 层级缩进 20px，每层左侧有一条细引导线；节点前有展开 / 收起的箭头。
- 节点类型：

| 节点 | 显示 |
|---|---|
| 摘要条目 | 等宽日期或时间（"10/09"、"15:00"）+ 层级名（"日结"、"小时摘要"）+ 条目文本；引用的是旧版本时，后面加 `text-3` 小字"引用 v1 · 最新 v2" |
| IM 原文 | 会话图标、发送者、时间、内容；右上角青色小标签"原文"；右下角有"上下文"链接 |
| 邮件原文 | 邮件图标、主题（书名号）、"发件人 → 收件人 · 时间"；右上角"原文"标签；点击打开邮件详情 |
| 日程原文 | 日历图标、标题、时间段、参会人数；右上角"原文"标签 |
| 降级框 | 降级样式的框：首行珊瑚色"原文已丢失 · 降级为 AI 当时概述"，正文是该小时条目的文本，下面两行 `text-2`："AI 概述 · 生成于 10/13 17:05"和丢失原因 |

- 默认只展开直接证据。底部有一个"展开到原文"按钮；原文超过 50 条时显示"还有 N 条"。

### 版本轨与差异框

- 版本轨：竖线，节点从新到旧排列。每个节点包括：
  - 等宽版本号；
  - `text-2` 时间和触发方式（"10/29 20:30 · 定时"）；
  - 一行变更说明（"并入周四日结 · 新增 2 · 修改 1"）；
  - 最终版的节点后面加"最终版"标签。
  选中的节点用琥珀色并带微光。
- 差异框，标题为"v4 相比 v3"：
  - 修改：旧文本（`text-3` 删除线）→ 箭头 → 新文本（`text-1`）；
  - 新增：绿色"+"加文本；
  - 删除：珊瑚色"−"加删除线文本；
  - 全量生成的版本：标题下显示"全量生成，按全文对比"，内容改为左右两列的完整条目。
- 底部两个按钮："对比两个版本"（幽灵按钮，打开选择两个版本的弹窗）和"重新生成 vN+1"（琥珀描边，点击后确认）。

### 日结小卡

- 用在回顾页的周和月视图里。
- 内容：头部是星期和日期（"周四 10/29"），正文是前两个条目的文本，最多两行，超出省略。
- 状态：

| 状态 | 显示 |
|---|---|
| 已生成 | 正常显示 |
| 已并入当前选中版本 | 琥珀描边 + 小标签"已并入 v4" |
| 未生成 | 虚线描边 + "20:30 生成" |
| 未来 | 淡虚线描边 + "—" |
| 无记录 | `text-3` 小字"无记录" |

- 点击跳到今天页的那一天。

### 覆盖条

- 一排小圆角格子，每格代表一天，宽约 10px、高 16px，格子间距 4px。
- 颜色：已备份 = 绿；缺口·已过期 = 珊瑚；缺口·可补救 = 琥珀；无数据 = `border` 色；今天的格子加一圈 `text-2` 描边。
- 缺口下方标注"10/12–10/14 备份失败 · 原文已过期"。
- 最右 7 格上方有一个细括号，括号上的文字二选一：
  - "7 天可补救窗口 · 全部已备份" + 绿色对勾；
  - "7 天可补救窗口 · 2 天未备份"（琥珀色）。
- 悬停在格子上显示：日期、状态、客户端条数和本机条数。

### 任务行

- 从左到右：琥珀开关、任务名（`text-1`）、说明（`text-2`）、时间规则输入框（右侧带铅笔图标）、上次运行（状态点 + 时间 + 结果）、下次运行（`text-2`）、"立即运行"幽灵按钮。
- 点击时间规则输入框，弹出编辑浮层：

| 任务类型 | 编辑内容 |
|---|---|
| 每小时 | "每小时第 [05] 分" |
| 每天 | "每天 [20]:[30]" |
| 每周 | "每周 [日] [03]:[00]" |
| 每月 | "每月 [1] 日 [03]:[00]" |

  超出允许范围时在浮层里用珊瑚色提示（例如"日结时间需在 12:00 到 23:59 之间"），保存按钮不可点。
- 停用后整行压暗，下次运行显示"已停用"。
- 运行中，"立即运行"变成"运行中…"并且不可点。

### 运行记录行

- 内容：状态点、等宽时间、任务和处理对象（"小时摘要 · 19:00"）、结果说明。
- 状态点颜色：绿 = 成功，灰 = 跳过，琥珀 = 手动触发，珊瑚 = 失败或中断。
- 点击展开详情：输入、产出的版本（可点击跳转）、耗时、失败原因。

### 其他基础组件

- 分段控件：当前项琥珀浅底、琥珀描边。
- 开关：开启为琥珀色。
- 按钮：
  - 主按钮：青色实底，深色文字；
  - 强调按钮：琥珀描边；
  - 幽灵按钮：`border` 描边。
- 输入框：`panel` 底、`border` 描边，聚焦时青色描边。
- 弹窗：`panel-raised` 底，居中，宽 640。
- 轻提示：右下角，3 秒后消失。

## 5. 页面

### 5.1 今天

**布局**：页头，下面两栏。左栏占 60%，是时间线卡；右栏占 40%，三张摘要卡纵向等宽排列。两栏都撑满视口高度，时间线卡内部可以滚动。

**页头**：
- 左边：小字"今天"（查看其他日期时显示"回到今天"链接），下面是大标题"10月29日 周四"，旁边是"‹""›"两个圆形按钮，用来切换日期。不能切到未来的日期。
- 右边：搜索框，加两个状态胶囊：
  - "● IM 备份 今天 02:00"（失败时变为"● IM 备份失败"，珊瑚色）；
  - "日结 20:30 已生成"（未生成时显示"日结 20:30 生成"）。

**左栏**：
- 卡片标题"今日时间线"（其他日期显示"时间线"），旁边小字"按小时 · 只显示有记录的小时"。
- 内容是时间轨加小时卡。只有今天显示"当前时刻"。
- 今天还没有记录时，显示空状态"今天还没有与我有关的记录"，下面一行写下次小时摘要的时间。

**右栏**：三张摘要卡。

| 卡片 | 标题（今天 / 其他日期） | 日期范围 | 页脚 |
|---|---|---|---|
| 日结 | "今天" / "10月27日" | "10/29 周四" | "1,284 条消息 · 与我有关 86 条 · 7 个小时摘要" |
| 周 | "本周至今" / "第 44 周" | "10/26 – 10/29" | "依据 4 份日结 · 查看版本 ›" |
| 月 | "本月至今" / "10 月" | "10/1 – 10/29" | "依据 16 份日结 · 查看版本 ›" |

## 6. 文案与格式

- 日期：
  - 页面标题："10月29日 周四"；
  - 卡片和列表："10/29"；
  - 范围："10/26 – 10/29"（两边有空格的短横）。
- 时间：
  - 当天："20:30"；
  - 相对："今天 20:30"、"昨天 20:30"；
  - 更早："10/25 03:00"。
- 时长："38 秒"、"1 分 12 秒"。
- 数量：千分位"1,284"，数字和单位之间空一格（"86 条"、"55 天"）。
- 版本号："v4"，用等宽数字。
- 触发方式：定时、补跑、收尾、手动、迟到重跑、启动补跑。
- 生成方式：增量、全量。
- 降级："原文已丢失 · 降级为 AI 当时概述"；丢失原因："IM 备份失败，原消息已过 7 天保留期"、"备份时原消息已不存在"、"邮件超过 3 个月未备份"。
- 空档："HH:00 – HH:00 无与我有关的消息"；单个小时："HH:00 无记录"。
- 演示脱敏打开时，以上所有文案里出现的人名、群名、金额都按规则替换。

## 7. 与原型的差异（原型里没画全的，以本节为准）

- **任务页**：链路图要有"次日补跑"回环；任务行的时间规则可编辑（见第 4 节"任务行"）。
- **证据抽屉**：原型底部不要"打开原会话"按钮，改成 IM 原文节点上的"上下文"链接；底部只保留"查看本条历史版本"。
- **备份页**：覆盖卡在原型里固定是 IM，实际要加来源切换的分段控件。
- **告警横幅**：原型里没画，按第 3 节实现。
- 原型里的人名、群名、数字都是虚构的。"IM 已备份 55 天"等数字由真实数据动态计算。
